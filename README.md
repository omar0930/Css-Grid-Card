# Omar's Grid Assignment 🌐📱

A responsive and visually engaging HTML/CSS layout project designed using CSS Grid and Flexbox. This project showcases a mock Apple-style marketing layout featuring products like iPhone 6S, iMac, iCloud, and more — optimized for all screen sizes with a clean modern design.

## 📁 Project Structure

```
/project-root
│
├── index.html           # Main HTML file
├── css/
│   ├── styles.css       # Base styles and layout grid definitions
│   └── media.css        # Media queries for responsiveness
└── Images/              # Image assets (you must add these manually)
```

## 📱 Features

- ✅ Responsive layout with CSS Grid and Flexbox
- 🎨 Modular and clean code structure
- 📺 Multiple sections: iPhone, Keyboard, iMac, iCloud, Gaming, iPad Pro, Twitter, TV
- 🎈 Visual flags (Popular, Best Choice) and elegant typography
- 💡 Optimized for Desktop, Tablet, and Mobile

## 📦 Built With

- HTML5
- CSS3
  - CSS Grid
  - Flexbox
  - Media Queries
